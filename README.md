# 設備点検管理デモ（再構築版）

> **重要:** これは以前 ChatGPT で作成・公開したアプリの元ソースコードではありません。保存済みの仕様説明をもとに新たに再構築した、GitHub Pages 対応の独立したデモです。公開中の既存アプリとは画面・実装・データ保存方法が異なります。

## 主な機能
- 点検箇所別のチェック項目と初心者向け「？」ヘルプ
- 点検結果の登録とブラウザ内への保存
- ダッシュボードへの集計反映
- 点検履歴と簡易報告書の表示・印刷（ブラウザの「PDFとして保存」でPDF化）
- スマートフォン対応

## ローカルで動かす
1. このフォルダを解凍します。
2. `index.html` を Chrome 等のブラウザで開きます。
3. 「点検入力」から記録し、「ダッシュボード」で結果を確認します。
4. 「報告書を表示・PDF保存」を押し、表示された画面の「印刷・PDFとして保存」から PDF を選択します。

Python・Node.js のインストールは不要です。

## GitHub にアップロードする
1. GitHub で新しい公開リポジトリを作成します（例: `inspection-demo`）。
2. リポジトリの **Add file → Upload files** を選択します。
3. `index.html`、`style.css`、`app.js`、`README.md`、`.gitignore` をアップロードして Commit changes を押します。
4. **Settings → Pages → Build and deployment** の Source を `Deploy from a branch` にします。
5. Branch を `main`、フォルダを `/(root)` にして Save を押します。
6. 数分後、`https://<GitHubユーザー名>.github.io/inspection-demo/` で確認できます。

## データの扱い・制限
- 記録は `localStorage` に保存され、**同じブラウザ・同じ端末内のみ**で利用できます。端末間同期・共有・バックアップ・ユーザー認証はありません。
- ブラウザの保存データを削除すると記録も消えます。個人情報や実際の点検記録を入力しないでください。
- サンプルの点検項目は学習・ポートフォリオ用であり、法定点検や専門的な安全確認の代替にはなりません。
- 本番利用には認証、サーバー側のデータ保存、バックアップ、権限管理、セキュリティ確認等が必要です。
